# target-run

## 1.0.0

### Major Changes

- be1d9d3: feat: initial release of `target-run`

  `target-run` is an OS and architecture-aware script dispatcher for `package.json` that resolves platform/arch-specific variants of npm scripts based on the current system. It supports a flexible resolution order and provides CLI options for dry runs, verbose output and optional/required script enforcement.
